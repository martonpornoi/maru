# Retired Marucon public-roster scenario

Status: Retired; retained as a decision pointer
Last updated: 2026-08-01

The 2026-07-31 scenario proved several useful product behaviors, but its
executable fixture combined two boundaries that Maru no longer accepts:

- it could import live public volunteer handles into local accounts; and
- it used the broad legacy bootstrap to give a platform administrator
  convention authority.

`seed_marucon_rehearsal` is therefore quarantined. Every invocation, including
all former command options, returns a stable retirement error before
validation, file or network access, or database writes. The former Awoostria
network adapter also raises before any network I/O.

## Behaviors retained elsewhere

The useful outcomes were not discarded:

- optional human login handles remain in platform identity;
- the edition-scoped minimized workforce structure projection remains;
- nested departments, reporting positions, multiple holders, and one person
  with several positions remain supported by the workforce model;
- registration-profile extensions remain append-only and enforce attendee,
  staff, or shared writer policy;
- authoritative ticket eligibility remains a product/entitlement fact rather
  than an attendee checkbox; and
- Convention work remains inside the unified `/admin/` shell without the
  global Quick Start strip.

## Supported replacement

Use `seed_demo_data`, which contains only deterministic synthetic `.invalid`
identities. Its two active Executive Boards are created through the real
provision, exact invitation, self-response, and two-controller activation
services. The platform administrator performs oversight but is never a member,
appointee, participant, registrant, workforce assignee, or convention-role
principal.

Continue the educational journey in `/admin/`:

1. inspect or create a Draft organization;
2. open Page 8, **Representation & access**;
3. complete the explicit Executive Board handoff with synthetic people;
4. create the convention series and edition; and
5. use the current hands-on tutorial and focused representation tests as the
   executable evidence.

The future Awoostria-shaped department template may reuse public department
taxonomy as synthetic configuration. It must not scrape, copy, or synchronize
real-person handles. Historical checkpoint files document the retired
experiment and remain append-only.
