# Project records

**Audience:** Maintainers and contributors planning or resuming work\
**Outcome:** Find current status and detailed planning records without placing
them in the newcomer path\
**Reading time:** 2 minutes to choose a record

Start with [CURRENT](CURRENT.md), the maintained project handoff. Use the
[roadmap](ROADMAP.md) for outcome order and the
[production-consolidation ledger](PRODUCTION_CONSOLIDATION.md) for exact
implemented, partial, absent, and deployment-gated status.

Backlogs, delivery plans, transition plans, and retired scenarios are
maintainer records. They support implementation and auditability but are not
introductory product documentation and may contain historical terminology.
