was written before the adapter. A verified person can follow labelled available
calls into explicit track/format/duration and subject-owned profile/consent input,

summary/selection/own-invitation fields; leads and accepted collaborators may
additionally read only their own configured profile. Reauthorization surrounds
the complete rendered response and verifies the sole submission cursor.

pending-input asset. It has no new domain writer, model, migration, runtime ACL,
API operation, current-profile member, production URL mount or other-module
side effect. Explicit call schema/version fences prevent source reinterpretation.

blank, non-public draft is allowed. Contradictory values are refused, not erased.
The policy code is identified honestly, without inventing organizer policy text.
