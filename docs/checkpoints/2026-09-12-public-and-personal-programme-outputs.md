independent owner authority, bounded formats and honest unavailable states.

owns that exact result. This checkpoint does not predict a #99 commit or merge.

Public output has genuine exact-profile public admission, exact immutable
reviewed Programme copy and current minimized Venue wayfinding. Complete
canonical/native release evidence and final owner/disclosure rechecks prevent
latest-copy substitution, partial output and stale last-good fallback.
The existing host-self query also stops returning withdrawn latest public copy,
without falling back or fetching private reviewer metadata.

Personal output independently composes explicit Programme host purposes,
approved own presence and retained Workforce work. The non-persistable
`scheduling.view_host_self` capability is unpinned in every current profile.
Workforce-only makes no Programme/release or Participation lookup. Actual own
records justify a minimized current Events name/version; empty scopes do not
discover edition names. Required host presence, event phase context, tentative
claims, confirmed work and ended history remain distinct. Current instructions
never silently relocate accepted work or prove attendance.

Closed deterministic typed/JSON and RFC 5545 outputs have row/text/byte bounds,
UTC-aware dates, safe escaping and stable calendar identities. Public and private
payloads are not interchangeable. Every HTML/print/download request authorizes
again; private responses are no-store. Combined private calendar imports are
withheld after host-release withdrawal/invalidation, while JSON/HTML preserves
known state and unchanged work. No imported-file update/erasure guarantee exists.
