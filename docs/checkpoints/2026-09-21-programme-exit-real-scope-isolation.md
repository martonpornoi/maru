Date: 2026-09-21. Focused #109/P12 evidence for the #189/#190 exit bundle;
not complete Programme isolation, human acceptance, certification or activation.

The opt-in `tests/rehearsals/programme_isolation_native.py` runner passed in
258.82s with actual temporary PostgreSQL, restricted candidate startup, owned
HTTPS, genuine backend authentication and public setup commands. It constructs
both a real sibling edition and a second real organization/edition. The latter
deliberately retains incomplete accountability; no unrelated grants are invented.
Private setup credentials cross only bounded child stdin, never command arguments
or diagnostic output. Scope IDs are canonical, distinct and checked against the
original foundation before constructing denial targets.

The original archive requester has positive home/task/stop controls. Anonymous
requests redirect to authentication. Existing foreign, sibling and mixed-scope
archive home/task/download requests refuse with non-disclosing, non-cacheable
responses. Other controllers and the Department intake person cannot retrieve
the original requester's task metadata or bytes. Actual logout separates the
sessions, and cookies are cleared even on observation failure. The archive is
explicitly cancelled afterward; the owned database is disposed and the unchanged
97-table excluded-owner baseline is verified through the journey.

Organization-level Maru operators genuinely hold Events transition and role-control
authority. The sibling edition's stop preview is therefore allowed, but its visible
access summary must identify that exact sibling rather than the original edition.
This does not confer separately approved archive-purpose authority. Earlier runs
2 and 3 incorrectly expected this legitimate access to fail and remain failures;
run 1 failed before setup because the new checkout lacked its temporary parent.
No application access policy was altered to make the rehearsal pass.

documents, bounded private subprocess failures, wrong archive identity, changed

They test the observers, not native authorization. Native run 4 is preserved as
