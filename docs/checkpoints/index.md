# Checkpoint archive

**Audience:** Maintainers and contributors reconstructing a completed milestone\
**Outcome:** Locate historical evidence without treating it as current guidance\
**Reading time:** 2 minutes plus the selected checkpoint

Read the [checkpoint system](README.md) before using this archive. Checkpoints
are append-only historical snapshots. They preserve what was known and verified
at a milestone; they are not revised when later work supersedes them.

Use [CURRENT](../project/CURRENT.md) for the maintained handoff and the
[production-consolidation ledger](../project/PRODUCTION_CONSOLIDATION.md) for
current implementation status. Search the archive by date, requirement, ADR,
or affected area only when historical evidence is needed.
