# Programme exit owner composition and bounded encoding

Date: 2026-09-20. Issue #189 within #108/P11 and #48 remains open.

## Outcome and boundary

The `codex/programme-exit-bundle` development branch composes all eight declared
archive owners through their public source-authorized queries. This is local
preparation for a larger complete archive/P11 delivery, not a separate feature PR,
protected delivery, activated profile, background task or usable download.

Programme retains explicit core/host/staffing/placement/lineage evidence with
separate source and archive-purpose checks. Applications retains reviewed-proposal
configuration, policy, case/decision lineage and current-authorized original clean
files, including still-readable historical seals. Private unsubmitted drafts,
stage/anonymity-withheld content, invitation secrets and foreign calendars remain
excluded by declared purpose, never hidden missing-owner success.

Scheduling retains complete history and original canonical identity artifacts,
including withdrawn releases, without changing ordinary serving rules. Workforce
retains Programme Shift links and history. Venues supplies current room wayfinding,
Events supplies exact current configuration, Authorization supplies admitted
immutable recipe definitions rather than private approvals/grants, and Audit
supplies independently admitted minimized generation receipts.

Full composition locks canonical parents/mutex, complete sorted Applications
Departments, then the complete requester/Programme-host person set before any child
audit. Source identity binds every non-Audit section/schema and exact original file;
fresh receipt IDs/times are not falsely treated as changed source state. Duplicate
file identities are accepted only for identical original bytes.

ADR 0109 chooses requester-only background tasks and private expiring PostgreSQL
chunk custody. Its lifecycle/native persistence/UI are not implemented by this
checkpoint. A new pure stream encoder supports the larger bounded capacity while
preserving the provisional codec's original limits. It emits deterministic stored
ZIP members to a private caller-owned sink, binds actual Events scope/profile and
requires rollback/disposal after a sink failure. Hashes are not signatures,
encryption, permission or database recovery.
