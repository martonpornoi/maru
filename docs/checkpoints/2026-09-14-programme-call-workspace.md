## Outcome and boundary

Applications supplies a dedicated dormant exact-Department call inventory and
complete manager configuration, metadata/policy editing, explicitly confirmed
edition-zone window replacement, track/format/contributor-field ordering and
removal, and existing activation/retirement/successor commands. The separate
[page contract](../product/page-contracts/programme-call-workspace.md) owns this
surface. ADRs 0051/0082/0084/0085 and the existing stable requirements remain
authoritative; no new ADR, writer, migration or profile promotion is needed.

The form adapter retains every supported question type, bound, option, condition,
classification, retention rule and catalog value. Whole-graph revalidation refuses
broken dependencies, duplicate codes and empty mandatory catalogs. The original
cursor is never replaced by a later source version. A stale retry may already
have succeeded; the page says to review the current call before a new attempt.
It does not claim receipt replay when its source preflight refuses an old cursor.

Metadata does not touch existing instants or precision. The separate confirmed
window replaces three explicit whole-minute local values. Strict DST handling
and an Events-version check under the existing canonical lock prevent silent
timezone reinterpretation. Applications' audit-backed exact Department-name
query uses a minimized Workforce reference without granting structure, holder,
proposal, profile or review authority.
