## Outcome and contract

An independently admitted exact Department now anchors a separate complete
call-management chooser. Every candidate requires its own current authority
before its name and stable code are resolved. Only ordinary absent permission
filters a choice; incomplete policy, unsupported obligations, overflow, missing
references, changed membership/decisions and required audit failure discard the
whole projection. Reauthorization and required per-choice protected-read evidence
precede release. No hidden names/counts, hierarchy, holders or proposal values
escape. The existing name-only Workforce reference remains unchanged; the new
purpose-minimized owner reference supplies ID/code/name only.

The dedicated Draft transfer excludes the source from its closed destination
field, visibly distinguishes duplicate names by code, explains retained history,
requires confirmation/reason and retains the original aggregate cursor and retry
identity. Only the existing `reassign_programme_call` writes. Its exact source and
destination authority, private-planning fences, canonical locks, version check and
receipt replay remain authoritative. Successful navigation enters the destination
overview, which authorizes independently. Source-unavailable and uncertain retry
responses never claim that an earlier transfer did not commit or open recovery.

The [page contract](../product/page-contracts/programme-call-workspace.md) was
extended before implementation. Requirements IDN-014, PRG-001/002/008/009/011,
AUD-001/003, PRI-001, UX-005 through UX-008, UX-019/020/027/029 and NFR-013 map
to ADRs 0051/0082/0084/0085 and existing owner boundaries. No ADR is reversed.

Accountable setup still owns first entry. No edition-wide call-management grant,
Workforce structure access, new domain writer, schema, production route, API
operation, profile promotion, email or unrelated-module side effect is added.
The dormant adapters can be reverted without altering owner schema or retained
evidence. This is not orphan recovery, rollback of a transfer or a data-deletion
operation. Current authorization is required for any subsequent owner command.
