## Contract and implementation

PRG-001/002/003/009, AUD-001/003, PRI-001, NFR-013 and existing form/shared-shell UX
contracts govern the [page contract](../product/page-contracts/programme-domain-references.md).
ADRs 0051/0082/0085/0100 remain unchanged. Applications owns the closed
`programme.call-track` and `programme.call-format` catalogs and canonical answer.
No schema, runtime grant, generic resolver or cross-module writer is introduced.

The exact applicable shared-answer task independently admits actual lead/accepted
collaborator and edit authority before showing complete bounded same-call choices.
It does not widen the ordinary lead-only workflow catalog. Native selection shows
labels/codes; preparation shows immutable guidance and explains that this additional
private answer does not change main selection, duration, routing or timetable.
Person and domain tasks share target-neutral source admission; person public
aliases, signing purpose and legacy answer digests retain their semantics.

Confirmation binds original target/kind/call/question, actor/tenant, proposal/call/
schema cursors and retry key in a bounded identifier-only purpose-signed proof.
New preview confirmation is unchecked. Stale/invalid requests retain original
intent; a stale preparation retains a neutral labelled choice without reading a
new catalog. The existing answer command alone writes and audits. Fresh membership
checks run after retained successful replay under existing source locks. Clear
writes None without bypassing required-answer sealing. No failed response
redispatches a write or silently rebases the request.

Current and current-seal personal viewers derive the exact target from authorized
answers. Separate reviewer/moderator/decider viewers retain exact assignment,
current seal, field/stage allowlist and sensitive-content authority. Canonical
anonymous omission precedes target lookup, including direct URLs. Empty and
unavailable states never substitute a different call entry. Pure formatting does
no target I/O; repeated full source/catalog/target comparisons withhold changed
responses. Return destinations independently authorize access.
