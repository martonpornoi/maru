Date: 11 November 2026. Scope: local workflow and evidence handling.

The maintainer approved routine agent-operated fictional testing, a lighter
local documentation route, reusable read-only checkers and continued work
within previously authorized scope. The candidate is on
`codex/ai-assisted-workflow-policy` from verified protected main
`0c6d0dbbeaae00068e7c769495cbd7c72fdaccaf`. It does not incorporate the
unrelated GUI repairs or alter the older working checkout.

[ADR 0134](../architecture/decisions/0134-bounded-ai-assisted-work-and-local-documentation-checks.md)
records the local routing and authority boundaries. Auto uses the shared CI
classification plus a complete tree comparison to admit only clean prose
additions and edits. It writes new scoped evidence alongside prior runs.
Ordinary, exhaustive, diagnostic and deferred database paths keep their
meaning. Hosted checks, protection, release rules, tenant isolation and real
human decisions remain unchanged.

The prepared-sign-in mode uses the existing strict Workforce fixture and
normal invitation commands. It supplies only fictional sign-ins, with no
convention work or authority prefilled. The default blank-start path stays
available for credential setup acceptance. No UI, demo seed, migration or
production behavior changes.

Verification is recorded separately for focused routing tests, the real
documentation path and the disposable prepared-sign-in startup. A smoke run
does not certify the candidate for protected merge or repeat the wider
Workforce browser acceptance. No issue closure, push, merge or deployment is
part of this local checkpoint.
