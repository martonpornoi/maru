## Outcome and boundaries

[ADR 0101](../architecture/decisions/0101-exact-purpose-release-change-comparisons.md)
adds independently authorized current-self hosting and exact operator-purpose
comparisons to the existing exact release/history foundation. Own approved
presence is compared by relationship plus occurrence; event phases are not
silently assigned as own work. Room/Department membership is applied separately
to both sides, so leaving a scope discloses no unadmitted destination and is not
global cancellation. Current relationship/membership versions remain separate
from immutable released sources. Both native manifests and independent owner
purposes are repeated before final authorization and mandatory audit.

Neither query accepts an arbitrary historical release or other recipient.
No private copy, personnel/contact directory, availability, Shift mutation,
delivery, acknowledgement, schema, route or profile activation is introduced.
Missing/oversized/moving evidence fails closed. Suppressed state is not empty
success, mass cancellation or a last-good fallback.
