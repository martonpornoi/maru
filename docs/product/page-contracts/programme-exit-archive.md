## Task and authority

An authenticated original requester deliberately exports one complete supported
Programme edition. The reserved shared-shell home is
`/admin/programme/archive/<organization>/<edition>/`; its acknowledged request is
`<task>/`, with private attachment retrieval at `<task>/download/`.
There is no directory, other-person selection, impersonation, bearer sharing,
email delivery or automatic polling. No production navigation link is installed
before final Programme promotion. Each reserved destination reauthorizes itself.

Static preview explains eight owner sections, reviewed-proposal scope, private
clean files, exclusions, limits, independent permissions and restricted custody.
It reveals no source labels or identities. Extra archive-request authority admits
a deliberate queue request, not source access. Current independent owner rights
are checked in generation and again before private metadata or retrieval.
The signed-in account and route scope, never submitted hidden account/tenant
fields, bind every command. Source drift, revocation, missing files and corruption
cannot yield a partial success attachment.

## Interaction and states

Use one H1, the shared main landmark, standard labels/buttons, visible focus,
responsive stacked content and no animation or script dependency. The request
requires an explicit restricted-custody acknowledgement. Preserve submitted
idempotency identity on validation/dependency failure; restarting with a new
identity is a deliberate choice. A successful request redirects to its exact task.

Display truthful phase/version and original database-clock expiry, never fake
percentages. Refresh is explicit because current owner checks can be expensive.
A ready, unexpired, currently authorized task offers an attachment. Cancellation
requires confirmation and the observed version; it removes only derived chunks,
not source records, holds or immutable task/audit evidence. Terminal requests can
be deliberately replaced with a new request linked to the old one. Expired access
does not pretend the worker has already disposed the stored bytes.

Malformed input returns field feedback; stale/conflicting or capacity-limited
commands give generic actionable feedback without foreign counts or labels.
Source denial/absence and dependency failure return no private task or partial
artifact. A worker failure has a closed safe code, not raw exception content.
No task can download after expiry merely because a page or earlier check succeeded.

## Custody and recovery explanation

Explain the fixed 24-hour access window, 20-minute worker budget, explicit retry,
128 MiB records-member and 1 GiB content ceilings (stricter source bounds apply).
The archive is restricted C3 evidence, not encrypted/signed output, a public
timetable, database backup or import. Keep it in controlled private storage; do not
upload it to a public archive checker. Verify manifest paths/sizes/hashes and inspect
schemas locally. Digests detect corruption, not authenticity. Live disposal cannot
erase downloaded copies or historical database backups. Stop-use is separate #190.
