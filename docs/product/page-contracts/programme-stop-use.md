# Stop Programme

Status: Candidate implementation; no production profile or route admission.
Requirements: EVT-007, ARC-003/005, AUD-001, NFR-013 and UX-005–008.
ADR 0111 governs the terminal contract; #190 supplies #108/#109/P11 within #48.

## Task and scope

The reserved shared-shell route is
`/admin/programme/stop/<organization>/<edition>/`. The authenticated ordinary
controller needs current independently proven role-management and Events
transition authority. Platform administration, an old receipt or a visible link
does not supply either permission. Scope comes only from the route and actual
signed-in account. No production navigation is installed before final promotion.

GET deliberately loads a complete minimized preview, not private source records.
Show the exact organization/edition identifiers, current lifecycle and versions,
collection totals and closed states from seven owners, retained grant dispositions,
pending work, stored release pointer and independently checked withdrawal right.
No person labels, proposal/review contents, source reasons, calendars, file bytes
or effect payloads belong to this purpose. Missing sources or overflow yield no
partial preview and no confirmation form.

## Deliberate confirmation and retry

Explain that stopping archives this Programme adoption, not the convention or
server. It withdraws a stored active timetable through the actual authorized
Scheduling command. It does not complete shifts, cancel physical commitments,
revoke shared authority, erase evidence or send external notifications. Retained
edition rights cannot override terminal write guards. Existing downloaded files
cannot be recalled; they are historical and retain their original finite expiry.

Require an explicit acknowledgement and a short accountable rationale. Bind the
form to the originally displayed Events versions, complete preview digest and
non-nil retry key. A POST never silently loads newer versions or replaces this
identity. Validation and uncertain dependency failures preserve original input;
a stale preview requires deliberate reload and renewed confirmation. Missing
withdrawal authority prevents confirmation. No JavaScript or animation is needed.

A committed result redirects to its exact receipt. Receipt detail is restricted
to the original actor with current controller prerequisites; it displays only
that actor's reason, terminal versions and retained outcome, not private owner
sources or another person's history. Every retry reauthorizes. Stopped context
offers no stop/reopen controls; recovery is documented fix-forward or consistent
restore, never a profile toggle. An old form cannot restart operation.

## Presentation and failure states

Use one H1 and the shared main landmark, native labels, visible keyboard focus,
stacked narrow-layout sections and an explicit Access explanation. Counts and
states are text, never color-only. The irreversible action is labelled
**Stop Programme and retain history**, not **Cancel convention**.

Malformed/duplicate/foreign posted fields are rejected. Unknown scope and missing
authority share a non-disclosing response. Stale versions/source identity yield
actionable conflict feedback. Database/source failure gives an unavailable result
without private exception text or a success claim. Responses are private/no-store.
The form is CSRF-protected and no GET mutates adoption state. There is no polling,
bulk stop, impersonation or browser-supplied actor/tenant selection.

## Acceptance

Automated checks cover strict forms, login/CSRF, original identity preservation,
closed input, ordinary-controller denial, current withdrawal prerequisite,
stale preview, native atomic rollback, exact replay and historical-only receipt.
Test responsive layout, keyboard, 200% zoom and reduced motion in a real synthetic
browser journey. Automated HTML evidence is not human or browser acceptance.
Historical/archive links independently reauthorize; stop does not waive source
freshness, privacy or retention. Integrated P11/P12 and protected delivery remain
separate gates.
