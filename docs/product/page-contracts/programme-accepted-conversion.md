## Audience, source and navigation

The exact-Department review root reserves `conversion/` for operators with
nondelegable `applications.convert_programme_acceptance` and independent edition
`programme.manage_items`. Neither grants review or private-item content access.
The complete bounded queue lists exact accepted decision/seal references using
call name, revision sequence, decision version and current review version. It
does not interpret an answer as a title or show scores, messages, rationale,
contributors or recipient states. Current eligibility and consumed status are
explicit; an old acceptance label is not a fresh permission or readiness claim.

The selected `conversion/{decision}/` fixes the exact decision and sealed
revision. Both owner scopes, source coherence and adapter pins are proved before
source disclosure. The canonical effective-source rule supplies the eligibility
hint, never a substitute for transactional command admission. Programme owns a
separate audited creation-cursor query under item-management authority, with no
inventory/title read and no import of Programme models into Applications.

## Explicit command and recovery

The operator deliberately enters a private working title and optional summary,
reason and explicit confirmation. No answer/profile/review content is copied.
Keep the original decision/seal, review cursor, Programme creation cursor and
retry identity. No automatic latest source, refreshed hidden version, inferred
host, public copy, consent, placement or staffing. Fresh conversion commits the
existing reciprocal owner evidence and seven unsatisfied readiness concerns.

An original POST first proves current person/tenant and both adapter pins, then
calls the existing conversion command before any fresh Department/capability,
source, planning or item read. This preserves the owner's deliberate late receipt
recovery after source or Department changes. It does not grant fresh conversion
or content. Validation/conflict/unavailability retains original form input only
after renewed fresh disclosure authority; denial returns generic unavailable text.
Never replace a key to bypass a consumed source. A receipt reports creation
versions, not the current item state.

The result links to the private item only after a separately authorized exact
Programme item read; unavailable access omits the link without losing the
successful receipt. The destination checks again. Decider navigation may offer
an independently admitted conversion task, never transfer decision authority.

## States and verification

Shared shell/assets, one H1/main, labelled ordinary controls, progressive opaque
references, focusable errors and pending-input protection. Test empty, historical,
eligible, consumed, stale source or either version, malformed/unknown/duplicate
input, unavailable dependency, readonly, denied, successful and replayed states.
Reauthorize and compare projections before and after rendering. Exact source
discovery is bounded and scope-filtered before pagination, with no hidden totals.

Database-free owner/query and real form/HTTP tests cover independent capabilities,
no private copy, tenant/edition/Department isolation, original two-version replay,
CSRF and disclosure revocation. Maintain native conversion tests but do not
collect/run them under ADR 0100; #102 owns restoration. Synthetic component browser
evidence does not replace #92 human/keyboard/all-width/zoom/screen-reader acceptance.
