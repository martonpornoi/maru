# Programme operator run sheets

- Status: Delivered dormant under ADR 0099 through PR #103; #108 connections
  retain separate development verification and final acceptance gates.
- Audience: Independently authorized room, Department and edition operators.
- Route family: Dormant `/admin/programme/run-sheets/`; no current profile or
  production URL is activated by #100.
- Requirements: SCH-006/008/009/010/012, PRG-008, HR-015, AUD-001,
  UX-007/008/013/029 and NFR-001/002/005/008/009/013.

## Purpose and scope

Show approved preparation, delivery and teardown times alongside exact reviewed
copy, current wayfinding and only the explicitly requested authorized delivery
or staffing fields. The three purposes are one room, one Department's rooms and
adopted linked work, or one whole edition. Department scope does not mean
Programme item ownership, all reporting-tree descendants or all venue rooms.

The server resolves the exact persisted target before protected discovery. An
identifier, filter, page visibility or saved projection grants no authority.
Every owner independently rechecks selected sources, fields and current scope.
No request accepts another person, arbitrary candidate/release or an access flag.
Unknown, inactive, foreign and denied targets share non-disclosing failure.

## Interaction and disclosure

Use the shared Administration shell, one main landmark and H1, a compact Access
explanation and source-state summary. Scope is explicit; navigation never lists
ungranted room or Department names. Generic layer controls request technical,
accessibility, media or staffing data; they do not imply permission. Default
output contains no optional protected layer. Requested denial never silently
unchecks a box and shows an apparently complete export.

The chronological run sheet identifies each immutable released envelope and
reviewed title, with current instruction versions in separate labelled sections.
Workforce demand terms and retained work intervals remain distinct. No person
roster, contact, host availability, review rationale or private discussion is
rendered. A live count of confirmed work is not attendance or renewed eligibility.

HTML, JSON, private calendar and print consume the same complete current query.
An export repeats the scope, selected layers, release identity/time, observation
time and owner versions. No field is obtained from a public payload or a private
draft. All transports are private/no-store and escape their own text format.
HTML gives only the shared navigation script a fresh per-response CSP nonce;
it does not permit arbitrary inline scripts. Mobile menu dismissal, focus
containment and focus return must work under the actual response policy.

## Guided continuations and final disclosure

The dormant edition entry at `/admin/programme/run-sheets/{organization}/{edition}/`
offers complete bounded current room, Department and whole-edition purposes by
owner-supplied labels. Every purpose independently requires Scheduling geometry,
Programme reviewed-copy and Venue membership/wayfinding fields before its label is
read. Department purposes also require Workforce membership when that adapter is
adopted; no detailed staffing or delivery layer is preselected. Planner, public,
Applications and Workforce-directory permissions are not substitutes. Entry does
not read a release, working item, personnel directory or instructions.

Ordinary missing permission omits that purpose. Incoherent, oversized, moving or
unauditable sources withhold the complete catalog without hidden labels/counts.
Current owner names and policy/source facts are rechecked after rendering. Room
names include their local venue context; indistinguishable permitted choices need
organizer clarification, never silent deduplication or a guessed target. Empty
entry is not a claim that the edition has no rooms, Departments or approved work.
Links must reverse and resolve to the exact current scope and have no optional
layer parameters. Destinations reauthorize independently. The shared shell keeps
one H1/main, visible keyboard focus, explicit Access and no write controls.
An independently admitted return from run-sheet/now-next allows a deliberate new
scope choice without carrying extra layers to that different purpose.

The interactive run sheet offers independently admitted same-purpose now/next
and notice continuations without listing other rooms or Departments. Same-purpose
output links preserve all explicitly requested layers; fixed labels and URLs grant
no authority. Missing, denied or shadowed routes in the current URL configuration
are omitted. Optional link changes cause a link-free rerender, never a command.

All four formats re-read the complete same-actor owner projection after rendering
and compare every source fact while aligning only the fresh observation timestamp.
The original check time and bytes are retained, not renewed. Late purpose/field
loss, changed instructions, geometry or retained work, audit failure or backwards
time withholds the response. This adds no public fallback or remote-copy erasure.

## States and recovery

- Authorized empty: explicit no approved rows in this exact scope; no foreign
  names, counts or release rows appear. Optional requested fields still authorize.
- Unrequested/unadopted: separately labelled, never mistaken for no staffing need.
- Absent/withdrawn/invalidated: no approved rows; calendar unavailable. Saved
  downloads may be stale and cannot be remotely recalled.
- Denied: non-disclosing 404; malformed admitted input: 400.
- Missing/oversized/moving source or audit failure: 503 with no partial output;
  retry performs a complete fresh owner read rather than a last-good fallback.
- A ready canonical release does not imply profile or production activation.

## Accessibility and acceptance

Use explicit labels, ordinary controls, visible keyboard focus and text states.
Reflow narrow layouts without page-level horizontal scrolling; private fields
are not hidden merely with CSS. Print preserves scope, versions and caveats.
Reduced motion is respected. Automated synthetic role/state, keyboard and width
rehearsals do not establish native print, actual 200% zoom, screen-reader or
representative-human comprehension. Those checks remain a separate #92 subtask.

Test ordinary policy at each exact scope, independently denied fields, cross-
tenant/person failures, foreign selectors, requested layers on empty results,
native withdrawal/invalidation, current instruction and membership movement,
predecessor work, incomplete bounds, audit failure and cross-format disclosure.
Verify no Registration, Participation, payments, attendance or external sending.
