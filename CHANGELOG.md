# Changelog

Maru records externally meaningful changes in GitHub Releases. Each release uses
the repository's CalVer policy and links the exact pull request, commit, OCI image
digest, provenance, documentation, API schema, and operational notes.

The project has not published a gold release. Development history remains in
the append-only [checkpoint ledger](docs/checkpoints/README.md); it is not a
substitute for curated release notes.
